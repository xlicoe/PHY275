Course Description

Classical mechanics (or classical mech) is the foundation upon which modern physics is built. In this course, we will start from Newtonian mechanics, but move on to the more powerful, coordinate-free modeling tool of Lagrange and Hamilton. These "new math" also bridge nicely to quantum and relativistic physics.

Classical mech can be done purely analytically. However, this course will also integrate a light computational thread to solve problems that analytical techniques cannot touch.

This is the first time I teach this course, so lots of iterations will be done through this Fall. Please check this repo regularly.
